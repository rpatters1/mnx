Jumps (D.S. al Coda)

In this example, the bars are to be performed in this order: 1, 2, 3, 4, 5, 2, 3, 6.

The "toCoda" jump at the end of bar 3 is ignored the first time through, because it only applies after the "dsAlCoda" jump has been taken.
