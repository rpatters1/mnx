The bracket enclosure object

Type: Dictionary

A pair of parentheses or square brackets enclosing notation. The property using this object defines which notation is enclosed.

Attributes

Name Type Required? Description
symbol bracket enclosure symbol Yes

Plus globally available attributes: _c, _x, id

Parent objects

This object is used by the following parent objects:

  • accidental display: "enclosure"
  • kit note markings: "enclosure"
  • note markings: "enclosure"
