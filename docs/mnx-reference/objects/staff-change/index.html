The staff change object

Type: Dictionary

The staff change object changes a single staff of a system's layout for a range of rhythmic positions within that system. Only the staff that changes is specified. All other staves continue to follow the layout, and the number and order of staves, and their groups, symbols and barline connections, are fixed for the entire system.

A staff change can either replace the staff's sources (for example, to change stem directions, or to split a part's voices onto different staves) or cut the staff away (for cutaway scores, where a staff starts or ends in the middle of a system).

Attributes

Name Type Required? Description
cutaway boolean No If true, the staff is cut away for the range of this change: its staff lines, its own barlines and its contents are not drawn, but its vertical space in the system is kept. When the staff resumes, its clef and key signature (and time signature, if appropriate) may be drawn as they would be at the start of a system. The same applies to the staff's label: it may be drawn at the point where the staff resumes, taken from the staff's "label"/"labelref" or from those of the sources in effect at that point. This lets a staff re-enter with a different instrument, by giving the resumed range new sources.

How group barlines and group symbols (brackets, braces) are drawn across a cut-away staff is left to the consumer. For example, when string divisi staves enter mid-system, a consumer may draw the divisi group's bracket at the point where the staves enter rather than at the start of the system.

If cutaway is true, "sources" must not be provided. If cutaway is not true, "sources" is required.

If not provided, the default value is false.
end measure rhythmic position No The position where this change ends (exclusive). Starting at this position, the staff reverts to its definition in the layout. It must be later than "start" and must be within this system.

If not provided, the change lasts until the end of the system.
sources An array of staff source objects No The staff sources to use for this staff within the range of this change. These replace the staff's "sources" from the layout.

Required unless "cutaway" is true, in which case it must not be provided.
staff ID Yes The ID of the staff to change. This must be a staff within the layout used by the containing system.
start measure rhythmic position Yes The position at which this change begins (inclusive). It must be within the containing system.

Plus globally available attributes: _c, _x, id
