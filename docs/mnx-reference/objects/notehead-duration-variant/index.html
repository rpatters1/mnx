The notehead duration variant object

Type: String

A duration-related form within a semantic notehead shape family. Selecting a form does not change the event's duration or specify a playing technique. For example, a quarter-note event can use a half-note diamond head while retaining its quarter-note stem and rhythmic value.

Not every family distinguishes all forms. Consuming software selects the applicable glyph within the family. An explicit glyph takes precedence over this selection.

Allowed values:

Value Description
"breve" The form normally used for breves.
"closed" The closed form normally used for quarter notes and shorter values.
"default" Uses the normal duration-based selection for the applicable notehead design. For a kit note using its component's design, this retains the component's duration variant. Otherwise, the form follows the event's displayed duration.
"half" The form normally used for half notes.
"whole" The form normally used for whole notes.

Parent objects

This object is used by the following parent objects:

  • kit notehead: "durationVariant"
  • notehead: "durationVariant"
