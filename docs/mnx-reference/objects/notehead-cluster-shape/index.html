The notehead cluster shape object

Type: String

A shape family for a shared cluster head. The consuming software determines its proportions and construction for the cluster's span and the event's displayed duration. The shape does not change the pitches selected by "pitchSelection" or prescribe a performance technique.

Allowed values:

Value Description
"box" A rectangular block spanning the endpoint notes.
"default" The cluster shape is determined by the consuming software.
"diamond" Diamond noteheads at the endpoint notes, joined by a thick line.
"oval" Oval noteheads at the endpoint notes, joined by a thick line.
