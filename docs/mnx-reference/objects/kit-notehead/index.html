The kit notehead object

Type: Dictionary

The default notehead design for a kit component. It specifies a semantic shape family, an optional glyph, a triangle direction, and a duration variant. Hiding and parentheses are properties of individual noteheads and are not part of this design.

Each kit note selects a duration-appropriate glyph from this design using its event's displayed duration unless "durationVariant" selects another form or an explicit glyph is supplied. A kit note whose shape is omitted or "default" uses this design. An explicit per-note shape such as "oval" replaces the design, including its glyph, triangle direction, and duration variant.

Attributes

Name Type Required? Description
durationVariant notehead duration variant No The duration-related form of the notehead, selected independently of the event's duration. This changes only the head: stems, flags, beams, augmentation dots, rhythmic duration, and performance still follow the event. An explicit glyph overrides this selection.

For this component, "default" selects the form appropriate to the displayed duration of each kit note's event.

If omitted, the value is "default".
glyph smufl glyph No An explicit SMuFL glyph for this notehead. An explicit shape is required when a glyph is supplied. Use a known shape to retain its semantics while refining its appearance, or ("custom") for an otherwise unclassified head.

The glyph overrides duration-dependent glyph selection, including "durationVariant". Per-note display settings still apply. The glyph does not change pitch, duration, or performance.
pointing up or down No The direction in which the tip of a triangular notehead points, independently of stem direction. This property is only allowed when shape is "triangle".

If omitted, the default value is "up". An explicit glyph overrides the rendered appearance.
shape notehead shape No The semantic shape family for this kit component's noteheads. "default" lets consuming software determine the shape. An individual kit note can select another shape without changing this component.

If omitted, the value is "default".

Plus globally available attributes: _c, _x, id
