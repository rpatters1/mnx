The event lyric line extender object

Type: Dictionary

This represents a lyric extender line (also called a word extension): a horizontal line after a syllable, indicating that the syllable is sustained across subsequent events.

An extender line is encoded on the event lyric line of the syllable that starts it.

Attributes

Name Type Required? Description
show boolean No Whether the syllable has an extender line. A value of false explicitly specifies that there is no extender line, even where one would normally be expected (for example, under a textless passage).

If not provided, the default value is true.
target ID No The ID of the last event under which this extender line extends, i.e., the final event of the melisma.

The extender line covers the events from the event that starts it through the target event, including the full width of the target event. The target event should not have a syllable in the same lyric line (i.e., with the same lyric line ID).

The exact horizontal end point is left to consuming software, because engraving conventions vary. For example, some conventions end the extender lines of all lyric lines at a common point.

If not provided, consuming software should determine the extent of the extender line according to its own logic.

This is ignored if show is false.

Plus globally available attributes: _c, _x, id
