The notehead cluster pitch selection object

Type: String

The semantic pitch selection for a notehead cluster. Keyboard key colors refer to sounded pitches, independent of their enharmonic spelling, key signature, or transposed display.

Allowed values:

Value Description
"blackKeys" A cluster containing all black-key pitches within its span. Black keys correspond to C sharp, D sharp, F sharp, G sharp, and A sharp in each octave. Enharmonic spelling does not change which keys are selected.
"chromatic" A cluster containing all white-key and black-key pitches within its span.
"default" The cluster's pitch selection is determined by the consuming software.
"whiteKeys" A cluster containing all white-key pitches within its span. White keys correspond to the natural pitches C, D, E, F, G, A, and B in each octave.
