The notehead object

Type: Dictionary

Describes the semantic shape and display of a single notehead. The same object is used for pitched notes and kit notes.

An explicitly selected shape other than "default" or "custom" identifies a duration-aware family rather than a single glyph. Consuming software selects the filled, open, whole, or breve form appropriate to the event's displayed duration, where the family has such distinctions. In tuplets and multi-note tremolos, use the displayed note value rather than the elapsed performance duration. Shapes such as "x" or "plus" need not have a filled/open distinction. No general filled/open override is provided.

Shape, parentheses, and hiding are independent. These properties do not change pitch, duration, or performance.

MNX does not currently define staff settings that assign notehead shapes by pitch or staff position, such as shape-note or percussion notation. Applications may still encode such settings using vendor extensions. When a notehead's shape is omitted or set to "default", consuming software may use those settings to choose its shape. An explicit shape, such as "oval" or "diamond", overrides that setting.

Attributes

Name Type Required? Description
glyph smufl glyph No An explicit SMuFL glyph for this notehead. An explicit shape is required when a glyph is supplied. Use a known shape to retain its semantics while refining its appearance, or ("custom") for an otherwise unclassified head.

The glyph overrides automatic duration-dependent glyph selection. Parentheses and other display settings still apply. The glyph does not change pitch, duration, or performance.
hide boolean No Whether to suppress the notehead and its parentheses. The default is false. This setting does not affect stems, flags, beams, accidentals, augmentation dots, or other markings. The note retains its rhythmic space, pitch, duration, and performance.
parentheses boolean No Whether to enclose the notehead in parentheses. The default is false. This does not change performance.
pointing up or down No The direction in which the tip of a triangular notehead points, independently of stem direction. This property is only allowed when shape is "triangle".

If omitted, the default value is "up". An explicit glyph overrides the rendered appearance.
shape notehead shape No The semantic shape family of this notehead. Shape selection does not change pitch, duration, or performance. For example, "diamond" does not by itself specify an artificial harmonic, and "slash" does not specify pitchless notation or a beat repeat.

If omitted, the value is "default".

Plus globally available attributes: _c, _x, id
