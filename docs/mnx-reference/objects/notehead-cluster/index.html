The notehead cluster object

Type: Dictionary

A group of pitches represented by a shared notehead spanning its bottom and top notes in one event. The duration of the containing event determines whether the cluster head is closed or open, and whether it has augmentation dots. Consuming software determines the head's geometry and its attachment to stems and other rhythmic notation.

A cluster may span multiple staves within the same part, for example to represent an arm cluster. Consuming software determines how the block crosses the space between staves.

An event may contain multiple disjoint clusters, with ordinary notes outside their spans, including between an upper and a lower cluster. Kit notes cannot serve as endpoints.

Attributes

Name Type Required? Description
hide boolean No Whether to suppress the shared cluster head and its parentheses. This setting does not affect stems, flags, beams, accidentals, augmentation dots, or other markings. It does not change the cluster's rhythmic space, pitches, duration, or performance.

If omitted, the value is false.
parentheses boolean No Whether to enclose the entire shared cluster head in one pair of parentheses.

If omitted, the value is false.
pitchSelection notehead cluster pitch selection No The selection of pitches within the cluster's span. Consuming software determines the notation used to communicate this selection, including any collective accidental signs beside the shared head. These signs apply to the cluster as a whole.

If omitted, the value is "default".
span ID pair Yes The IDs of the two notes that bookend this cluster. The "start" ID identifies the note with the lower sounded pitch, and the "end" ID identifies the note with the higher sounded pitch. The IDs must identify distinct notes with different sounded pitches.

Both notes must be in the containing event. They may be on different staves within the same part.

The cluster includes the pitches selected by "pitchSelection" within the inclusive range bounded by the sounded pitches of its two endpoints. The endpoint pitches must belong to that selection. Only the bottom and top notes are encoded; the pitches between them are implied by "pitchSelection".

An ordinary note in the containing event must lie outside the cluster's pitch range. Cluster spans in the same event must not overlap.

Plus globally available attributes: _c, _x, id
